context-passationPython 3.8+Installeur · 3 hooks

Des sessions de plusieurs heures. Sans perdre le fil.

Le skill mesure les tokens réellement utilisés. Juste avant la compaction automatique, Claude écrit une fiche : ce qui est en cours, les décisions, la prochaine étape, les fichiers à relire. La compaction passe, la fiche revient, et il continue sans s’arrêter.

/model-regulatorPython 3Installeur · 1 hook, 2 sous-agents

Fable 5 quand ça vaut le coup. Opus le reste du temps.

Avant chaque prompt, un hook local note sa difficulté, sans dépenser un token. Sous Opus, le cœur difficile part vers un sous-agent Fable. Sous Fable, une fenêtre propose de redescendre pour les broutilles.

Télécharger Lire la fiche

Installer en une commande

La commande montre d’abord ce qui va changer (--dry-run) : relance-la sans cette option pour installer. L’installeur copie le skill et deux sous-agents, ajoute un hook à settings.json (sauvegardé avant), met le modèle par défaut sur opus[1m] et l’effort Fable sur high. Sans base de quota sur ta machine, ses seuils restent fixes.

Installe un skill.

Un skill est un dossier posé dans ~/.claude/skills. Rien d’autre à configurer.

  1. Télécharge

    Le fichier .zip du skill. Ils pèsent tous moins de 30 Ko : du texte, et parfois un script Python.

  2. Dézippe au bon endroit

    Dans ~/.claude/skills sur Mac et Linux, dans %USERPROFILE%\.claude\skills sous Windows. Tu dois y voir un dossier au nom du skill, avec son SKILL.md.

  3. Ouvre une discussion Claude Code

    Tape / : le skill est dans la liste. La plupart se lancent aussi tout seuls, dès que ta demande leur correspond.

Deux skills ont un installeur — context-passation et model-regulator

Pourquoi

Ils travaillent par des hooks : des commandes que Claude Code lance avant un prompt ou après un outil. Un hook se déclare dans ~/.claude/settings.json, et c’est ce que fait l’installeur, après avoir sauvegardé le fichier.

Comment

Dézippe où tu veux, puis lance python3 install.py dans le dossier (python install.py sous Windows). Les hooks s’activent dans les nouvelles discussions.

Lis avant d’installer — un skill donne des consignes à ton agent

Tout est lisible

Un skill dit à Claude quoi faire, avec tes accès. Ceux-ci sont du texte et du Python, sans rien de compilé : « Lire la fiche » ouvre le SKILL.md de chacun, et le zip contient le reste.
